## 1. 产品定位

**一句话价值主张：**  
为 Web3 早期参与者提供 AI 驱动的空投机会识别与决策支持系统。

### 1.1 目标用户

| 用户画像 | 特征 | 核心需求 |
|---------|------|---------|
| **空投猎人** | 熟悉 Web3，追求早期机会 | 自动发现 → 快速决策 → 可执行清单 |
| **投资研究员** | 关注赛道趋势，需要数据支撑 | 结构化评分 → 历史数据 → 导出报告 |
| **项目开发者** | 需要竞品分析 | 同类项目对比 → 热度追踪 |

### 1.2 核心场景

```
用户旅程：
1. 每日登录 Dashboard
2. 查看「今日新发现」列表（按热度排序）
3. 点击单个项目 → 查看详情页
   - 6 维评分雷达图
   - AI 生成的 reason（为什么值得关注）
   - 竞争度指标
   - 可执行 checklist（如何参与）
4. 标记为 FARM / WATCH / IGNORE
5. 查看历史决策记录
6. 导出为 CSV / JSON
```

## 2. 功能矩阵

### MVP (Phase 1)

| 功能 | 描述 | 优先级 | 验收标准 |
|-----|------|--------|---------|
| **项目发现** | 每日自动抓取 5-10 个新项目 | P0 | 数据库每日增量 ≥ 5 条 |
| **评分引擎** | 6 维评分 + 总分计算 | P0 | Golden Test 16 条 100% Pass |
| **Dashboard** | 单页 HTML 展示项目列表 | P0 | 支持排序 + 筛选 |
| **详情页** | 展示单个项目详情 | P0 | 包含评分 + reason + checklist |
| **决策标记** | FARM / WATCH / IGNORE | P1 | 支持多选 + 状态持久化 |
| **API 契约** | RESTful API | P0 | 符合 `API_SPEC.md` |

### V2 (Phase 2)

| 功能 | 描述 | 依赖 |
|-----|------|------|
| **用户系统** | 多用户隔离 | ADR-008 |
| **高级筛选** | 按赛道 / 融资 / 时间筛选 | MVP 完成 |
| **导出功能** | CSV / JSON 导出 | V2 前端 |
| **订阅通知** | 每日邮件摘要 | V2 后端 |
| **LLM 增强** | reason 生成调用真实 LLM | ADR-001 可选插件 |

## 4. 非功能需求

### 4.1 性能

| 指标 | MVP 目标 | V2 目标 |
|-----|---------|---------|
| **API 响应时间** | p95 < 500ms | p95 < 200ms |
| **Dashboard 加载** | < 2s（10 项目） | < 1s（100 项目） |
| **每日批处理** | < 10min（10 项目） | < 30min（100 项目） |

### 4.2 可用性

- **MVP**：单实例，允许计划停机
- **V2**：99.5% 可用性，支持滚动升级

### 4.3 可扩展性

- **MVP**：支持 10-50 项目/天
- **V2**：支持 100-500 项目/天

## 5. 产品路线图

### Phase 1 - MVP (W1-W4)
- ✅ 项目工程基础设施

- ⏳ 单页 Dashboard

- 订阅通知
- 数据导出
- 竞品对比

## 6. 产品边界（不做什么）

| 不做什么 | 原因 |
|---------|------|
| ❌ **链上交易** | 不操作用户资金，避免托管风险 |
| ❌ **自动 Farming** | 仅提供决策支持，不代用户操作 |
| ❌ **KYC/账户托管** | 不接触私钥 |
| ❌ **投资建议** | 输出仅作参考，不构成投资建议 |

### V2 成功指标

- [ ] 用户决策留存率 ≥ 60%
- [ ] API 可用性 ≥ 99.5%
