# Backlog Template

> 产品 / 技术 Backlog，用于长期需求跟踪。

---

## 字段说明

| 字段 | 说明 |
| --- | --- |
| ID | 唯一编号，如 `B-001` |
| 标题 | 一句话描述 |
| 类别 | Feature / Tech Debt / Bug / Research / Docs |
| 优先级 | P0 / P1 / P2 |
| 状态 | 待评估 / 已排期 / 实现中 / 已完成 / 已搁置 |
| 价值 | 业务价值或技术价值 |
| 复杂度 | 粗略估算（S / M / L / XL） |
| 依赖 | 前置依赖 |
| 备注 | 补充说明 |
