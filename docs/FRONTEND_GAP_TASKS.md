## F. 基础架构层（P0 — 阻塞所有页面补齐）

### F1. 侧边栏导航骨架重构
- **现状**：❌ 前端用顶部水平导航（`Nav.tsx`，3 项），设计稿为 240px 固定侧边栏（9 项 + logo + API 健康点 + 版本号 + 引擎徽章）。`AppShell.tsx` 存在但未被 `layout.tsx` 引用。
- **产出物**：重写 `layout.tsx` 使用侧边栏布局（logo + 9 项导航 + 底部 API 健康点 + 版本号 + 引擎徽章）；<960px 折叠为 64px 图标栏 + hover tooltip；移除旧顶部 nav 和移动端底部 emoji nav。
- **验收**：所有 9 个导航项可见（未实现页显示但点击提示「即将上线」或跳空路由）；侧边栏在亮/暗主题下正确渲染；<960px 自动折叠为图标栏。
- **依赖**：F2（图标系统先行，否则侧边栏无图标可用）。

### F2. Lucide 图标系统接入
- **现状**：❌ 前端全面使用 emoji/文字符号（α/☾/☀/📋/📊/⚙️），设计稿统一使用 Lucide 图标（radar/satellite-dish/chart-line/clipboard-check/server-cog/bell/archive/bookmark/settings 等）。
- **产出物**：安装 `lucide-react`；替换全应用 emoji 为 Lucide 组件；主题切换图标用 `Sun`/`Moon`；导航图标对齐设计稿 `data-lucide` 属性。
- **验收**：前端无残留 emoji 图标（主题切换/导航/按钮/空态）；所有图标在亮/暗主题下对比度达标。
- **依赖**：无。

### F3. 统一卡片系统对齐
- **现状**：🟡 前端用 Tailwind `.card` 类 + 组件内联样式；设计稿有统一 `.dash-card`/`.ins-card`/`.ops-card`/`.pd-card` + token 化阴影（alpha ≤ 0.05）/圆角。
- **产出物**：在 `globals.css` 或 `ui.tsx` 中定义统一卡片 token（border-radius/shadow/border-color 对齐设计稿 `--radius-*`/`--shadow-*`）；各页面复用统一 Card 组件。
- **验收**：所有已实现页面的卡片视觉与设计稿一致（圆角/边框/阴影/内边距）；暗色模式正确。
- **依赖**：无。

## I. 全局功能补齐（P2）

### I1. 全局搜索框
- **现状**：❌ 设计稿每页 topbar 内置搜索框（`.app-search`），前端完全缺失。

- **验收**：所有页面顶栏布局一致（标题/副标题/操作按钮对齐）。

### I3. 引擎徽章

## 执行顺序建议

```
Phase 1（基础）:  F2 → F1 → F3 → I2
Phase 2（核心页）: G1 → G2 → G3 → H1 → H2 → H4
Phase 3（增强页）: G4 → G5 → G6 → H3
Phase 4（全局）:  I1 → I3
```

Phase 1 是基础设施，必须先完成；Phase 2 是高业务价值页面 + 已实现页面的关键缺失元素；Phase 3 是增强性页面；Phase 4 是全局打磨。

每个 Phase 内部任务可并行。跨 Phase 有依赖关系的需按序执行。
